Perbandingan Fitur, Keamanan & Parameter Teknis

Mengapa memilih PASETO dibanding JWT? Berikut adalah analisis parameter arsitektural dan kriptografi antara kedua standar.

Parameter / Karakteristik JSON Web Token (JWT / RFC 7519) PASETO (Platform-Agnostic Security Tokens)
Kerahasiaan Payload (Confidentiality) Terbuka / Plaintext
Payload hanya di-encode Base64Url dan dapat dibaca siapa saja tanpa kunci secret.		 Terenkripsi (Mode Local)
Pada mode local, payload dienkripsi dengan AEAD sehingga 100% rahasia dan tidak terbaca.
Kerentanan alg:none & Header Spoofing Rentan secara Desain
Header token menentukan algoritma. Bug implementasi sering membiarkan alg:none atau key confusion attack.		 No Algorithm Agility
Algoritma terkunci permanen pada versi protokol (v4.local / v4.public). Header tidak bisa diubah.
Pilihan Primitif Kriptografi Fleksibel
Mendukung puluhan kombinasi cipher, termasuk yang sudah usang atau lemah jika salah konfigurasi.		 Modern & Terstandarisasi
Hanya menggunakan primitif kriptografi terkuat (AES-256, Ed25519, XChaCha20, BLAKE2b).
Kecepatan Eksekusi & Latensi (Throughput) Cepat di HS256, Lambat di EdDSA
• HS256 (MAC): ~16.000 ops/s (0.067 ms)
• EdDSA (Ed25519): ~730 ops/s (1.524 ms)
Terbebani 2x JSON parsing (header & claims) dan 3x Base64Url decode di tiap token.
Unggul Telak (Low Overhead)
• v4.local (AEAD): ~26.400 ops/s (0.038 ms)
• v4.public (Ed25519): ~7.600 ops/s (0.134 ms)
v4.public 10x lebih cepat dari JWT EdDSA! v4.local lebih cepat dari JWT HS256 berkat cipher native XChaCha20.
Ukuran Token & Overhead Bytes Overhead +157 B s/d +200 B (+57% - 72%)
• HS256: 433 Bytes (+157 B overhead)
• EdDSA: 476 Bytes (+200 B overhead)
Header Base64Url 20 B + Signature 43 B (HS256) atau 86 B (EdDSA).
Ringkas (+187 B / +68%)
• v4.local: 463 Bytes (+187 B overhead)
• v4.public: 464 Bytes (+188 B overhead)
Pada mode Ed25519, PASETO v4.public justru 12 Byte LEBIH KECIL dari JWT EdDSA (464 B vs 476 B)!
